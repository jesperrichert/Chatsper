Chatsper is a Open Source and free to use Twitch Bot. It can be used as Self Hosted version on a VPS or your own PC. Or you use the Hosted Version at [@Chatsper](https://chatsper.jespersen.zip)...

## Installation
You can choose between two types! 
- Use the native app on your Computer (Read More)
- Use Docker to run the chatsper Docker image (Read More)
- Or use the Hosted Version at [@Chatsper](https://chatsper.jespersen.zip)
